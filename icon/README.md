# Logo assets

- `logo.png`：使用者提供的完整演唱會 Logo，供程式標頭及「關於」頁顯示。
- `app-icon.png`：以完整 Logo 左側圖案為目標，由圖像工具整理成正方形圖示素材。
- `app.ico`：Windows 多尺寸圖示（16、24、32、48、64、128、256 px）。

原始 Logo 與相關名稱／圖案之權利歸各自權利人所有；這些圖像素材不包含於本專案原始碼的 MIT 授權。顯示 Logo 不代表本工具獲官方認可。

重新轉換 ICO：`powershell -ExecutionPolicy Bypass -File scripts\convert-icon.ps1`。
